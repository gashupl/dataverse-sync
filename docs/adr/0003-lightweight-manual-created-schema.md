# ADR-0003: Lightweight database schema in code

- **Date:** 2026-07-24

## Context
Implement Dataverse tables schema to avoid hardcoded table and columns names

## Decision
To avoid auto-generated by svcutils heavy class model we decide to implement light model by ourselves.  

## Consequences
Because required classes has been created by hand, it is required to modify them manually in case of source schema changes.
